# Анкеты на классах

Переработка программы «Анкеты» с занятий 5–6: вместо словарей — объекты
`Student` и `Teacher` с общим предком `Person`, проверки перенесены в
конструкторы, журнал ведёт класс `Registry`.

## Возможности

- Чтение анкет из текстового файла `input.txt` (по 5 полей в строке).
- Создание объекта нужного класса по первому полю строки (`s` / `t`).
- Валидация ФИО, почты, телефона, группы/кафедры с понятными причинами отказа.
- Сбор бракованных строк: номер строки, исходный текст, причина.
- Сортировка принятых анкет по ФИО.
- Вывод таблицы: №, ФИО, роль, группа/кафедра, замаскированный телефон.
- Статистика: принято/отклонено, распределение по ролям и по группам.
- Сохранение результатов в `ok.txt` и `errors.txt`.

## Структура проекта
.
├── Program.cs // запуск, вывод таблицы и статистики
├── Person.cs // Person, Student, Teacher, AnketaError
├── Registry.cs // загрузка, хранение, статистика, сохранение
├── input.txt // исходные данные (создаётся вручную)
├── ok.txt // принятые анкеты (создаётся программой)
└── errors.txt // бракованные строки с причинами (создаётся программой)

## Формат файла input.txt

Одна анкета — одна строка, поля разделены `;`:
тип ; ФИО ; почта ; телефон ; группа_или_кафедра

- `тип` — `s` для студента, `t` для преподавателя;
- последнее поле: у студента — **группа**, у преподавателя — **кафедра**;
- пустые строки пропускаются молча;
- строки, не прошедшие проверку, попадают в `errors.txt` с причиной.
